# CONVERSATION-ARCHIVE — what these files are

The raw exported histories behind every document in this repo. Kept as the
receipts: when a guide says a decision was made, the conversation that made it
is here. Consult them only when the documents are missing the *why* — the
documents are the distilled truth.

## What's in here

**September 28, 2026 exports** (8 files, `ai-studio-export-*` + `zai_export_*`):
the original build conversations — the site design (Night Garage v2), the
deliverables v1–v3 era, and the early business planning.

**October 3, 2026 exports** (3 files, `zai_export_2026-10-03-*.md`):
the consolidation-thread conversations — the v4 bug hunt, the v5 fix, the
Flight Plan, the state correction.

**`early-source-extracts/`** (5 text files, `file1-extracted.txt` …
`file5-extracted.txt`): plain-text extracts of the earliest source PDFs
(business-plan era, pre-repo). The original PDFs were not carried into this
repo — the extracts have the same content at a fraction of the weight.

## Handling notes

- These contain unfiltered personal and business detail — one more reason the
  repo should stay **private**.
- File names with spaces were normalized (`zai_export_2026-10-03 (2).md` →
  `zai_export_2026-10-03-2.md`, etc.). `-3` and `-3b` are two distinct exports
  that arrived with near-identical names — both kept, both unique.
- Nothing here is load-bearing for running the businesses; deleting this
  folder changes no instructions anywhere.
